# Circuit geometry

`yas_marina.geojson` contains an OpenStreetMap-derived raceway centerline licensed under ODbL 1.0 (`© OpenStreetMap contributors`, https://www.openstreetmap.org/copyright).

`yas_marina_openf1.json` is the same centerline aligned to OpenF1 session 9839 local x/y coordinates by `scripts/align-circuit-geometry.py`. Alignment uses driver 1 lap 39 and has 5.12 m RMS error. The 12 m width is an estimated visualization width, not an official asphalt boundary.
